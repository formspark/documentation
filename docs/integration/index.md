# Integrations

An integration sends every submission your form receives somewhere else, as
well as to your Formspark dashboard. Connect as many as you like on the same
form: they all run on each submission and none of them replaces your
submissions list.

Connect them from the **Integrations** section of your form's settings in the
[dashboard](https://dashboard.formspark.io).

## Collect submissions in a document

Formspark creates the document for you and keeps appending to it. Rows sync on
a schedule, so a submission appears shortly after it arrives rather than
instantly.

- [Google Sheets](./google-sheets) — a spreadsheet, one row per submission
- [Notion](./notion) — a database, one page per submission
- [Airtable](./airtable) — a base, through Make

## Get notified in chat

- [Slack](./slack) — post every submission to a channel

## Send submissions to your own code

- [Webhooks](./webhooks) — an HTTP request to a URL of your choice
- [Zapier](./zapier) — thousands of apps, no code needed
- [Make](./make) — visual scenarios, no code needed

## Enrich what you collect

- [UTM parameters](./utm-parameters) — record the campaign a submitter came
  from

## Related

Email is not an integration: notifications to you and automatic replies to the
submitter are configured in the **Emails** section instead. See
[email notification settings](/dashboard/email-notification-settings) and the
[autoresponder](/dashboard/autoresponder).
